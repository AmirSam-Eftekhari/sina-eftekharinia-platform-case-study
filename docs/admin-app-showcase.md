# Admin app showcase

Expo Router app (package `sina-admin`, dark UI). Screenshots pending ([REQUIRED.md](../screenshots/REQUIRED.md)).

- **Activation:** enter a one-time code; device registered.
- **Tabs:** Dashboard, Content, Tickets, Shop, Health, Settings.
- **Content:** page editor, list editor (reorder with up/down), item editor with English and Persian fields, photo upload, translation suggestion, publish/unpublish/discard, preview.
- **Tickets:** event editor (poster, status, scheduled publishing, custom information blocks).
- **Shop:** product editor, inventory adjustments, shop settings.
- **Health:** run and view website/SEO/cloud checks.
- **Settings:** active sessions, end session, add device, activity log.

UI strings are English. Device behavior has **not** been verified in this review.
