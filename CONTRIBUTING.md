# Contributing

This repository documents a case study; it contains no application code, so there is nothing to build or run.

Welcome: corrections of factual errors, broken links, typos and diagram fixes.
Not accepted: source code, credentials, personal data, or screenshots containing private information.

When proposing a factual change, cite the evidence (file, test or command output) so it can be verified. Claims that cannot be substantiated will be labeled "unverified" or removed.
